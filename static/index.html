simkl-mcp

model context protocol server for simkl unofficial

Connect your MCP client to Simkl to track movies, TV and anime. An independent, unofficial project built with Cloudflare Workers, Agents SDK, MCP SDK and OpenAPI-generated tools. Not affiliated with Simkl.

Repository README / documentation Capabilities

Connect with Streamable HTTP

Add this URL to a client supporting MCP over Streamable HTTP (preferred):

https://YOUR-WORKER/mcp

Your client discovers OAuth configuration, registers itself and opens Simkl sign-in. Authorize access to finish connecting. Credentials stay in the OAuth flow; this page only displays public metadata.

For local development use http://localhost:8787/mcp. Older clients can use /sse (legacy SSE transport). See the README for Worker secrets and setup.
